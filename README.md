# IPL-Analysis-Dashboard
Interactive IPL Analysis Dashboard built using PowerBI to analyze team, player, match, venue, and season-wise performance. Performed data cleaning, transformation, data modeling, and DAX-based KPI creation to generate meaningful insights. 

IPL Analysis Dashboard | Power BI

 Project Overview

The **IPL Analysis Dashboard** is an interactive data analytics and visualization project developed using **Microsoft Power BI**. The project analyzes IPL match data to identify important trends and insights related to **teams, players, matches, venues, runs, wickets, toss decisions, and match outcomes**.

The dashboard transforms raw IPL data into meaningful visualizations and interactive reports, helping users easily compare team and player performance across different IPL seasons.

 Objectives

* Analyze IPL team performance across seasons.
* Evaluate player batting and bowling performance.
* Analyze match results and winning trends.
* Identify the impact of toss decisions on match outcomes.
* Analyze venue-wise match performance.
* Compare team and player statistics.
* Provide interactive filtering for better data exploration.
